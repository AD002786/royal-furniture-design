# Royal Furniture & Design

Storefront prototype for Royal Furniture & Design (Atlanta, GA).

- `index.html` is the whole site: home, collection pages, product pages, bag and email sign-up. No build step.
- `products.json` holds the 100 launch products (retail prices only).
- `img/` holds product photos, room scenes and logo files.

Live on GitHub Pages from the `main` branch.

To turn on email sign-ups, set `SIGNUP_URL` near the top of the script in `index.html` to your Shopify, Klaviyo or Mailchimp endpoint.
